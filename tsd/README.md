# 技术规格说明书（TSD）

本目录存放 Autoflow backend 的技术规格说明书。说明书由 AI 根据代码或设计生成，由本仓库负责人维护。

## 必要要素

每份文档开头写明：

| 要素 | 内容 |
| --- | --- |
| 作者 | 负责该功能的研发 |
| 时间 | 文档生成日期 |
| 关联服务 | 本仓库的 `backend`、`core`，以及这次改动依赖的外部服务 |
| 关联功能模块 | 对应代码模块，例如 `crm/today_highlights` |

技术规格写接口、数据、任务、权限和代码落点。用户可见行为写在 `fsd/`。

开发前应先有完备的 TSD，再按这份 TSD 实现。

## 怎么追加

已提交的说明书不再修改。功能增加或迭代时，新增一份 TSD，在新文档里指向上一份。

文件名与对应的 FSD 使用同一日期和范围，例如 `2026-10-19-release.md`。
