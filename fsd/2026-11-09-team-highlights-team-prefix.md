## 1. 这次做什么

卡片标题仍是「团队今日重点｜日期」。团队卡上的小节和蓝链统一加「团队」前缀。本来就带「团队」的不加第二遍。

| 位置 | 文案 |
| --- | --- |
| 需介入标题 | 团队今日需介入 |
| 拜访对照 | 团队上周拜访 / 团队本周拜访。周一正文末尾蓝链也是「团队上周拜访」；周五正文不放该蓝链，改由底部「团队已拜访」承接，见后续周五说明书 |
| 报告入口 | 团队重点商机、团队人效、团队经营趋势 |
| 日报 / 周报 | 团队日报、团队周报 |
| 底部小节 | 团队本周 |
| 本周按钮 | 团队待完成、团队已拜访、团队例会复盘 |

「查看」「更多（N）」不加「团队」前缀。一线「我的今日重点」仍写「立即处理」，不因本文件改文案。

「团队待完成」只按本周预计完成日和未完成状态筛任务，不再带负责人姓名；打开后能看见哪些任务，由任务页权限决定。一线「本周待完成」仍筛本人，不变。

## 2. 验收

- 团队卡上能看到「团队今日需介入」，以及带「团队」前缀的报告入口、日报或周报、本周按钮。
- 拜访对照标题带「团队」；「团队人效」没有「团队团队人效」。
- 「团队待完成」链接没有 `owner_name`。
- 一线销售「我的今日重点」卡文案仍是「立即处理」，「本周待完成」仍筛本人。
- 工作台团队今日重点页的 tab 标题仍按接口返回，不因这次发卡文案改动。
