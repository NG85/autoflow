本文件只改销售负责人「团队今日重点」卡片上的文案。页面 tab、一线单独「我的今日重点」卡不改。历史说明书不改。

## 1. 这次做什么

卡片标题仍是「团队今日重点｜日期」。个人块和团队块同卡时，用「我的」/「团队」前缀区分。本来就带「团队」的不加第二遍。

| 位置 | 文案 |
| --- | --- |
| 折进的个人块标题 | 我的立即处理 |
| 需介入标题 | 团队今日需介入 |
| 拜访对照 | 团队上周拜访 / 团队本周拜访；蓝链「查看团队上周拜访」或「查看团队本周拜访」 |
| 报告入口 | 团队重点商机、团队人效、团队经营趋势 |
| 日报 / 周报 | 团队日报、团队周报 |
| 底部小节 | 团队本周 |
| 本周按钮 | 团队待完成、团队已拜访、团队例会复盘 |

「查看」「更多（N）」以及个人块下的「建议关注」「下周待确认」不加前缀。一线单独发卡仍写「立即处理」。

「团队待完成」只按本周预计完成日和未完成状态筛任务，不再带负责人姓名；打开后能看见哪些任务，由任务页权限决定。一线「本周待完成」仍筛本人，不变。

## 2. 验收

- 有个人折进时，卡片上先见「我的立即处理」，再见「团队今日需介入」。
- 拜访对照和底部入口都带「团队」；「团队人效」没有「团队团队人效」。
- 「团队待完成」链接没有 `owner_name`。
- 一线销售「我的今日重点」卡文案仍是「立即处理」，「本周待完成」仍筛本人。
- 工作台团队今日重点页的 tab 标题仍按接口返回，不因这次发卡文案改动。
